=========================================================
  activation_linux.py — инструкция по запуску
=========================================================

ЧТО ЭТО ТАКОЕ
-------------
Небольшая плашка в правом нижнем углу экрана: цветной пингвин Tux,
градиентный заголовок «Активация Linux» и подпись
«Перейдите в раздел «Параметры», чтобы активировать Linux.»

Окно без рамки, всегда сверху, клики проходят сквозь него (нажать на
плашку мышкой нельзя — она не мешает работе).

ВАЖНО: несмотря на слово linux в имени файла, скрипт работает ТОЛЬКО
на Windows. Он использует win32-вызовы (ctypes.windll.user32,
SetProcessDpiAwareness, атрибут -transparentcolor), которых в Linux нет.
На Linux он не запустится.


ЧТО НУЖНО УСТАНОВИТЬ
--------------------
1) Python 3 (подойдёт 3.8 и новее, рекомендуется 3.10+)
2) tkinter — графическая библиотека, входит в стандартный установщик
   Python для Windows

Сторонних библиотек (pip-пакетов) скрипту НЕ требуется — он использует
только стандартную библиотеку Python (tkinter, ctypes, math, sys, time).
Поэтому файл requirements.txt пустой (только комментарии).


ШАГ 1. УСТАНОВКА PYTHON
-----------------------
Если Python ещё не установлен:

  1. Скачайте установщик с https://www.python.org/downloads/windows/
  2. Запустите его.
  3. ОБЯЗАТЕЛЬНО поставьте галочку «Add python.exe to PATH»
     в первом окне установщика.
  4. Нажмите «Install Now».
  5. В списке компонентов должен быть включён пункт
     «tcl/tk and IDLE» (по умолчанию включён) — это и есть tkinter.

Проверка, что всё встало. Откройте командную строку (cmd) или PowerShell
и выполните:

    python --version
    python -c "import tkinter; print('tkinter OK')"

Первая команда должна вывести версию (например, Python 3.12.4),
вторая — строку tkinter OK.

Если вторая команда выдаёт ошибку ModuleNotFoundError: No module named
'tkinter' — переустановите Python с галочкой «tcl/tk and IDLE».


ШАГ 2. УСТАНОВКА ЗАВИСИМОСТЕЙ
-----------------------------
Перейдите в папку со скриптом 
и выполните:

    pip install -r requirements.txt

Так как внешних зависимостей нет, команда просто завершится сообщением
вида «Requirement already satisfied» или ничего не сделает — это нормально.
Главное, чтобы не было ошибок.

Если pip не найден, используйте:

    python -m pip install -r requirements.txt


ШАГ 3. ЗАПУСК
-------------
Из папки со скриптом:

    python activation_linux.py

Или двойным щелчком по файлу activation_linux.py (если .py связан с Python).

Плашка появится в правом нижнем углу экрана и будет висеть поверх
остальных окон.


ПАРАМЕТРЫ ЗАПУСКА
-----------------
  --seconds N   автоматически закрыть плашку через N секунд
                (N может быть дробным, например 2.5)

Примеры:

    python activation_linux.py
    python activation_linux.py --seconds 10
    python activation_linux.py --seconds 0.5


КАК ЗАКРЫТЬ
-----------
  * нажать Esc (плашка должна быть в фокусе — она забирает фокус
    при запуске)
  * либо Ctrl+C в консоли, из которой запущен скрипт
  * либо просто закрыть окно консоли
  * либо запустить с --seconds N, чтобы она закрылась сама

Если плашка «не реагирует» на Esc — кликните по ней нельзя (клики
проходят сквозь), поэтому просто используйте Ctrl+C в консоли или
закройте консоль.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
* «python не является внутренней или внешней командой»
    Python не добавлен в PATH. Переустановите с галочкой
    «Add python.exe to PATH» либо запускайте через полный путь,
    например:
        C:\Users\Администратор.DESKTOP-5LF1MH8\AppData\Local\Programs\Python\Python312\python.exe activation_linux.py

* Ошибка ModuleNotFoundError: No module named 'tkinter'
    Переустановите Python, включив компонент «tcl/tk and IDLE».

* Окно появилось, но фон вокруг пингвина не прозрачный (чёрный /
    тёмно-синий прямоугольник вместо прозрачности)
    Атрибут -transparentcolor поддерживается не всеми темами Windows.
    Попробуйте сменить тему оформления на стандартную (Параметры →
    Персонализация → Темы).

* Плашка не поверх других окон
    Убедитесь, что не запущен полноэкранный режим другого приложения
    (игры, видеоплееры в fullscreen) — они перекрывают topmost-окна.

* Плашка мигает / дёргается анимация
    Это нормально: заголовок и блики перерисовываются каждые 80 мс.

* Запуск на Linux
    Не поддерживается. Скрипт написан под Windows API.
